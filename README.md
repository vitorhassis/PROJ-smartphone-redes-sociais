# 📱 Smartphone - Redes Sociais  


---

## 📌 Sobre o projeto  

Este é um exercício prático onde desenvolvemos uma interface de **smartphone interativo** que exibe perfis de redes sociais ao clicar nos ícones correspondentes (cursoemvideo).  

🔗 **Demonstração:** *[smartphone-redes-sociais.vercel.app]*  

---

## 🎯 Funcionalidades  

✔️ **Interface de um smartphone** simulada com HTML e CSS  
✔️ **Ícones interativos** que exibem a foto do perfil da rede social correspondente  
✔️ **Design responsivo** para se adaptar a diferentes tamanhos de tela
